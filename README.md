# Automatic Street Light Using Arduino

## About
This project automatically turns the street light ON when it is dark and OFF when there is enough light.

## Components
- Arduino UNO
- LDR Sensor Module
- LED
- 220Ω Resistor

## Working
The LDR detects the light intensity. Arduino reads the LDR value and controls the LED automatically.

**Dark → LED ON 💡**  
**Bright → LED OFF**

## Software
- Arduino C/C++
- Wokwi Simulator

## Applications
- Street lights
- Parking areas
- Garden lights
- Energy saving

## Future Scope
The project can be upgraded with IoT, solar power, and motion sensors.
